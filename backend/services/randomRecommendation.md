# 随机美食

在桌面或手机的“更多”菜单中选择“随机美食”开启一轮推荐。首次抽取记录当前地图中心；“再换一家”保持该中心，“按当前地图中心重新抽取”更新中心并清空最近推荐记录。查看地点会打开现有地点弹窗。

`GET /places/random?lat=23&lng=113&excludeIds=1,2`

- 无需登录；半径固定为 5km 直线距离，与地图缩放、当前已加载标记无关。
- 先按球面包围矩形粗筛，再精确计算距离；包含 5km 边界，排除无效坐标和分类含“避雷”的地点。
- 完整候选池少于 5 家时返回 `place: null`，提示“附近好像没有结果，换个地方试试吧”。
- `excludeIds` 可选，最多两个地点 ID。先判断完整候选池数量，再排除最近推荐的两家。
- 原始权重：`W = 1 + 1/(1+d/2) + 0.3*C + 0.4*f/(f+5)`。`d` 单位为公里，`C` 复用 `placeDetailCompleteness`，`f` 为收藏用户去重数量。
- 抽取概率为剩余参与店铺的 `W / sum(W)`，不做 Min–Max 归一化，不使用 AI 服务。
- 响应包含 `place`、`distanceKm`、`candidateCount`，并禁止缓存。参数错误返回 400；查询失败返回 500，与候选不足区分。
- 前端关闭面板时取消在途请求，忽略过期响应；抽取期间禁用重复操作。

验证：在 `backend` 目录运行 `npm run test:random`。使用临时数据库检查公式、概率分布、范围边界、收藏人数、防重复、候选门槛及 HTTP 接口，不修改应用数据库。
